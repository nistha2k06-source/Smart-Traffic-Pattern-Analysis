# Smart Traffic Pattern Analysis 🚦
## Overview
Smart Traffic Pattern Analysis is an R Programming mini-project that analyzes vehicle counts, identifies peak traffic hours, and displays traffic patterns through an interactive dashboard.
## Objectives
- Analyze hourly vehicle counts.
- Calculate total and average traffic.
- Identify peak traffic hours.
- Classify traffic density as High, Medium, or Low.
- Visualize traffic data using interactive graphs.
## Features
- Traffic summary cards
- Bar chart for traffic volume
- Line chart for traffic trends
- Editable vehicle counts
- Dynamic dashboard updates
## Technologies Used
- R Programming
- HTML
- CSS
- JavaScript
- Chart.js
- Plumber API
- JSON

## Requirements
- R and RStudio
- Required R packages used by the project
- A modern web browser

## How to Run
1. Open RStudio.
2. Install the packages required by the R API.
3. Run the R API server on port 8000.
4. Open `index.html` in a web browser.
5. View traffic statistics and graphs.
6. Change vehicle counts and click **Update Graphs** to update the analysis.
The API must be running for the dashboard to load and update traffic data.
Conclusion
This project demonstrates how R programming and web technologies can be used together to analyze traffic data and visualize useful traffic patterns.
